# v0.2.0

`PM Method Agent` 的多轮协作与记忆闭环预览版。

这一版的重点不是把项目包装成完整平台，而是让它从“方法内核验证版”前进一步，变成一个可以本地体验连续产品判断的 agent 内核。

## 当前已具备

- CLI、统一 agent、本地 HTTP 服务和最小网页 demo
- 工作区、案例、历史消息和运行时状态
- 连续追问、回答承接和阶段转场提示
- 记忆建议、用户确认、记忆管理和记忆引用展示
- OpenAI-compatible 的 LLM 适配骨架，并保留本地规则回退
- 运行时事件摘要、恢复建议、开放事项和执行账本
- 真实问题试跑文档、人工冒烟文档和自动化回归测试

## 当前重点

这一版重点验证的是：

- 用户能不能从一句模糊草稿开始，而不是先整理完整需求
- 系统能不能连续承接 2 到 4 轮补充，而不是每轮重开
- 系统能不能说明当前卡点、承接方式和下一步
- 记忆使用能不能被用户看见、确认、编辑和撤回
- 网页 demo 能不能作为轻量体验入口，而不是复杂后台

## 当前还没做

- 完整云端多用户服务
- 正式 IDE 插件或 skill 包
- MCP 外壳
- sub-agent 编排
- 完整 PRD 生成
- 复杂团队协作和权限体系

## 推荐体验方式

统一 agent 入口：

```bash
PYTHONPATH=src python3 -m pm_method_agent.cli agent \
  --workspace-id demo \
  "前台最近老是漏提醒患者，我在想是不是要处理一下。"
```

继续补充背景：

```bash
PYTHONPATH=src python3 -m pm_method_agent.cli agent \
  --workspace-id demo \
  "这是一个 ToB 医疗服务平台，主要通过网页端使用，前台在操作，店长会看结果。"
```

本地网页 demo：

```bash
PYTHONPATH=src python3 -m pm_method_agent.cli serve --port 8011
```

然后打开：

```text
http://127.0.0.1:8011
```
