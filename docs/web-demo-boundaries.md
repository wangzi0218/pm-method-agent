# 网页演示边界

这篇说明本地网页演示现在能做什么、不能做什么，以及为什么不一开始就做成完整平台。

## 一句话定位

网页演示是 `PM Method Agent` 的轻量试用入口。

它让用户不用记命令，也能体验：

- 输入一句真实草稿
- 查看当前审查卡
- 继续补充一轮
- 切换最近案例
- 查看记忆建议和运行状态

它不是完整 SaaS，也不是团队后台。

## 为什么先做轻

网页比 CLI 更容易让用户产生完整产品期待，例如：

- 能不能登录
- 能不能跨设备同步
- 能不能团队共享
- 能不能上传项目资料
- 能不能在网页里直接执行本地工具

这些方向以后可以讨论，但 `v0.2` 更重要的是验证一件事：

`网页入口是否真的能让产品经理更自然地完成多轮问题定义。`

## 当前能做

### 发起分析

用户可以输入：

- 模糊想法
- 用户反馈
- 指标异常
- 带方案倾向的需求

网页只把原话交给服务层，不在前端重新判断阶段。

### 展示当前卡片

网页会展示当前案例的主卡片，包括：

- 当前阶段
- 当前判断
- 关键问题
- 继续前需要确认的点
- 建议下一步

第一版优先保证读得懂，不追求复杂组件化。

### 承接多轮补充

用户可以继续补一句：

- 补场景
- 补角色
- 补证据
- 回答决策关口

同一工作区会继续承接当前案例。

### 查看历史和切换案例

网页支持：

- 查看最近案例
- 切换当前案例
- 看到这段过程推进到了哪里
- 回到上一次没看完的分析

这是网页比纯命令行更自然的部分。

### 查看记忆建议

网页支持：

- 查看系统建议记住的信息
- 选择记住、只用于这次或不记
- 查看这一轮沿用了哪些项目背景或偏好
- 在发现背景不对时选择“不是这个项目”

长期记忆不应静默写入。

## 当前不做

### 不做团队后台

暂不支持：

- 多人协作
- 团队案例池
- 评论、指派和流转
- 组织权限和审计

### 不做云端账号系统

暂不支持：

- 注册登录
- 云端同步
- 跨设备恢复
- 多租户托管

### 不做完整配置中心

暂不支持：

- 模型配置面板
- 规则可视化后台
- 复杂审批策略编辑器
- 项目设置中心

这些能力会明显拉大产品范围，不适合放进 `v0.2`。

### 不做本地代理控制台

网页暂不默认暴露：

- 执行本地命令
- 读写任意本地文件
- 管理完整工具链

原因是安全边界会变复杂，也会让网页从“产品分析入口”变成“本地代理控制台”。

### 不做通用聊天页

网页演示聚焦：

- 问题定义
- 决策挑战
- 验证设计
- 多轮承接
- 记忆确认

如果用户只是想自由聊天，不是当前主场景。

## 默认部署方式

`v0.2` 默认是本地形态：

- 后端服务在本机运行
- 网页从本机服务打开
- 数据存在本地存储目录
- 一个浏览器页面默认对应一个本地使用者

启动方式：

```bash
PYTHONPATH=src python3 -m pm_method_agent.cli serve --port 8011
```

访问：

```text
http://127.0.0.1:8011
```

## 对后续产品的意义

网页演示不是终点，它主要验证：

- 产品经理是否更愿意在网页里连续补充
- 审查卡是否能被快速看懂
- 历史和记忆是否真的减少重复输入
- 哪些能力必须继续放在本地，哪些以后可以云端化

如果这些问题没有验证清楚，不建议直接进入完整平台开发。
